# SpawnGate — Плагин для Purpur / Paper (1.20+ / 1.21+ / 26.2)

Инновационный плагин для умного онбординга игроков, защиты спавна и системы заявок.

## Основная идея и этапы

### 1. Авторизация (AuthMe)
* При входе на сервер игрок **НЕ** блокируется и **НЕ** получает слепоту, пока не завершит регистрацию/вход в **AuthMe**.
* Это полностью предотвращает случайные кики по таймауту 30 секунд.

### 2. Чтение правил (Первый этап)
* Как только игрок зарегистрировался или вошел в аккаунт, плагин проверяет, прочитал ли он правила.
* Если правила не прочитаны:
  * Игрок получает эффект **Слепоты** (`Blindness`) и **Бессмертия**.
  * Полная **заморозка**: игрок не может двигаться, прыгать, писать в чат или использовать команды.
  * В чате открываются интерактивные правила (по умолчанию **8 страниц**, настраиваются в `rules.yml`).
  * **Защита от скипа:** На каждой странице действует таймер ровно **20 секунд**. Кнопка перехода на следующую страницу заблокирована, пока таймер не истечет.
  * Если игрок выходит с сервера, номер страницы сохраняется в SQLite базе — при повторном входе он продолжит с того же места.
  * На 8-й странице после 20 секунд активируется кнопка `[✔ Я ПРОЧИТАЛ И СОГЛАСЕН]`. После нажатия все эффекты снимаются.

### 3. Режим «Гость» и Зона спавна (Второй этап)
* Игрок может свободно играть и строить в обычном мире за пределами спавна.
* В зоне **300×300 блоков в каждую сторону** от нулевых координат (квадрат **600×600**, от `X: -300, Z: -300` до `X: +300, Z: +300`) во всех мирах:
  * **РАЗРЕШЕНО:** свободно бегать, открывать **двери**, бить мобов и других игроков (и получать урон — бессмертия на спавне нет!).
  * **ЗАБЛОКИРОВАНО:** ломать блоки, ставить блоки, открывать любые контейнеры (сундуки, бочки, печи, шалкеры, воронки), использовать вёдра, рамки, кнопки, рычаги.
  * При попытке взаимодействия действие отменяется, а игроку приватно отправляется сообщение (с кулдауном **1 раз в 5 секунд**) со ссылкой на Discord `https://discord.gg/CAf7PbhZBW` и оставшимся временем до авто-верификации.

### 4. Верификация (Третий этап)
* **Автоматически:** после **48 часов чистого онлайна** (`playtime`) плагин автоматически выдает верификацию и снимает все ограничения на спавне.
* **Вручную администратором:**
  * `/verify <ник>` — подтвердить заявку игрока.
  * `/unverify <ник>` — отозвать верификацию.
* **Интеграция с LuckPerms:** при верификации автоматически выдаётся группа (по умолчанию `verified`) или право (`spawngate.verified`).

## Команды и права

| Команда | Право | Описание |
| :--- | :--- | :--- |
| `/verify <ник>` | `spawngate.admin` | Подтвердить заявку игрока |
| `/unverify <ник>` | `spawngate.admin` | Отозвать верификацию |
| `/spawngate reload` | `spawngate.admin` | Перезагрузить `config.yml` и `rules.yml` |
| `/rules` | *всем* | Просмотр страниц правил в чате |

*Право `spawngate.bypass` — обход всех ограничений на спавне (по умолчанию у OP).*

## Сборка плагина (Maven)

Для сборки `.jar` файла выполните в папке проекта:
```bash
mvn clean package
```
Готовый файл `SpawnGate-1.0.0.jar` появится в папке `target/`. Поместите его в папку `plugins/` вашего сервера Purpur.
